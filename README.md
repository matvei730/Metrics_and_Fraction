# Metrics and Fraction

Этот проект решает 3 проблемы:

1. Пложения,вычетания,умножения и деление обыкновенных дробей
2. Помогает перевести градусные меры из цельсия в фаренгейт и из фаренгейта в цельсий
3. Перевод из имперсих мер изчисления в общепринитами мер измерений.

## Разработка

В проэкте из пользуются три класса:

1. используется для арефметических действий с обыкновенными дробями.
2. используется для перевода градусных мер из цельсия в фаренгейт и из фаренгейта в цельсий.
3. используется перевод из имперсих мер изчисления в общепринитами мер измерений.
